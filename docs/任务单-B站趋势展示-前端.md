# 任务单：B站第三方行情趋势图（前端）

> 数据侧负责采集与入库；**你只负责把已有数据画出来**。
> 阅读顺序：本文件 → `docs/设计文档.md` §8.6（第三方参考的定位）

---

## 1. 数据在哪

`GET /api/snapshot` → `data.reference`：

```json
"reference": {
  "source": "B站 @芝士华莱士 显卡日报",
  "note": "第三方整理，非本站实测，仅供价格水位参考",
  "days": 7,
  "series": [
    {
      "model": "RTX 5080",
      "points": [
        {"date": "2026-10-18", "low_hist": 829900, "low_day": 839900,
         "msrp": 829900, "jd": 849900, "tb": 839900, "pdd": 829900, "yin": 819900}
      ]
    }
  ]
}
```

**金额单位是「分」**，显示要 `/100`。字段缺省可能是 `null`（某天某平台没数据），必须能跳过。

---

## 2. 要做什么

一个独立区块，**放在主列表下方**，标题写：

> 第三方行情参考 · 来自 B站 @芝士华莱士「显卡日报」
> （第三方整理，非本站实测，仅供价格水位参考）

### 2.1 折线图（核心）

- 每个型号一条线，**默认只显示 4 个型号**，其余用下拉/勾选切换（一次画 16 条会糊成一团）
- X 轴：日期（7 天）
- Y 轴：价格（￥）
- 图例：型号名 + 当前值
- **不要**把京东价混进同一张图（我们的京东价和第三方口径不同）

### 2.2 每型号的"当前水位"卡片

| 显示 | 字段 |
|---|---|
| 当日最低 | `points[最后].low_day` |
| 近 7 天最低 | `min(points[].low_day)` |
| 官方指导价 | `msrp` |
| 相对指导价 | `(low_day - msrp) / msrp`，正数=溢价、负数=低于指导价 |

高于指导价时用橙色标「溢价 X%」，低于时用绿色标「低于指导价 X%」。

### 2.3 四平台对比（可选，P1）

同一天的 `jd / tb / pdd / yin` 画成 4 根柱子，让用户看到"哪个平台水位低"。

> 注意措辞：这是**第三方整理的行情**，不是我们抓的实时价。文案里不要出现"我们抓取"。

---

## 3. 硬约束

1. ❌ 不许说"实时""本站价格"
2. ❌ 不许把第三方数据混进我们的主价/排序/好价判定
3. ✅ 必须显示来源与免责（上面那两行字）
4. ✅ `null` 值跳过，不要画成 0（画成 0 会显得暴跌）
5. ✅ 至少 1 个点才能画线；某型号数据缺失就整条不画，别画成直线

---

## 4. 验收

- [ ] 折线图能切换型号，默认显示 4 条
- [ ] Y 轴单位是 ￥，不是分
- [ ] `null` 不显示为 0
- [ ] 溢价/低于指导价用不同颜色
- [ ] 区块标题含来源与免责声明
- [ ] 主列表的价格、排序、好价判定**没有**被第三方数据影响

---

## 5. 数据更新节奏（告知即可，不用你处理）

数据侧每天更新一次（人工核对后入库）。若某天没更新，`points` 就少一天，你的图**自动少一个点**即可，不要报错。
