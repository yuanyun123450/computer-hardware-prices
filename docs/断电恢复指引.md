## 六、断电会不会损坏数据

不会：

- SQLite 用 WAL，写入是原子的；最坏情况是丢掉最后一次未提交事务
- 快照是「先写临时文件再 rename」，不会读到半个 JSON
- 计划任务在来电后按原频率继续，锁文件超过 35 分钟自动失效
