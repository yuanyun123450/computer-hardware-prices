## 2. 三个新增区块（这就是 A+C 的全部工作量）

### 区块一：历史位置（取代"好价"）

每个商品卡片主价下面加一行**位置标签**：

| 字段 | 展示 |
|---|---|
| `deal.vs_avg_pct` | 「比近 7 天均价 **低 12%**」/「高 8%」|
| `deal.vs_min_pct` | 「距历史最低 **+3%**」|
| `deal.at_hist_low` | 为 true 时才显示绿色徽标「**历史低位**」|
| `deal.hist_points` | < 5 时**不显示任何高低判断**，只显示「历史数据不足（n=3）」|

⚠️ **硬约束**：`at_hist_low=false` 时不许写"低点/值得买/抄底"；`hist_points<5` 时连百分比都别显示。

> 现状（必须知道）：**78/80 个商品的历史是平的**（只有 1~3 个采集点），
> 所以页面上大多数卡片应该显示「历史数据不足」。这是真实的，不要美化。

### 区块二：价格走势（用我们自己的历史，**不依赖第三方**）

每个商品卡片可展开一条走势线，数据就在 `deal.trend`：

```json
"trend_platform": "jd",        // jd = 京东自营历史；zol = ZOL 参考价历史
"trend_points": 3,
"trend": [{"t":"2026-10-19T21:21:43+08:00","p":338837}]
```

| 情况 | 展示 |
|---|---|
| `trend_points >= 3` | 画折线，X 轴时间、Y 轴价格（￥）|
| `trend_points == 2` | 两点直线 + 标注「数据积累中」|
| `trend_points <= 1` | **不画图**，显示「走势数据积累中」|
| `trend_platform === "jd"` | 标注「京东自营历史价」|
| `trend_platform === "zol"` | 标注「ZOL 参考价历史」|

⚠️ 硬约束：**不同 `trend_platform` 的商品不要拼在同一张图里**——京东价和 ZOL 参考价口径不同，混画会得出错误结论。

### 区块三：同型号横向对比（新）

`snapshot.model_groups[]` 已经算好分组：

```json
{"key":"vga|5080||16GB","label":"…","count":2,"live_count":2,
 "min_live":1689837,"max_live":1799800,"spread":109963,
 "items":[{"product_id":7,"brand":"映众","price_live":1689837}, …]}
```

页面做一个「同款比一比」视图：

- 按 `live_count` 降序展示（有京东价的分组优先）
- 每组一行：型号 + 有价数量 + **价差**（`spread`）
- 点开看组内各品牌的价格，最便宜的高亮
- 只有 1 个商品的组不显示（导出时已过滤）

### 区块四：券后到手价 —— **已下线（2026-10-20）**

> 读个人券需要装浏览器扩展，门槛太高。现在只展示京东页面价，并在价格旁标注「未计算折扣券」。
> 下面的规则保留作历史记录，实现时**不要**再渲染券后价。

- 用户券只来自 `/api/user-coupons`（扩展上报）或手动填写
- 计算走 `/api/quote`，前端不算
- 没有券时：只显示主价 + 平台立减，提示"未检测到你的券"
- 文案：`券后价基于你自己的券，因人而异`

```

         ￥16898.37            ← 主价：京东自营实时价（price_live）
```

```
         ￥ 无价格信息
         历史数据不足
         参考价 ￥1299（ZOL，可能滞后）
```

## 4. 字段清单（v3 新增标 ★）

| 字段 | 含义 |
|---|---|
| ★ `site.*` | 站点名/副标题/免责/卖点 |
| ★ `model_groups[]` | 同型号分组（含 min/max/spread）|
| ★ `deal.vs_avg_pct` / `vs_min_pct` | 相对均价/最低的百分比 |
| ★ `deal.at_hist_low` | 是否历史低位（≥5 点且有波动才可能为 true）|
| ★ `deal.hist_points` | 历史点数（<5 时不要下结论）|
| ★ `deal.hist_min` / `hist_max` / `hist_median` | 历史最低/最高/中位 |
| `deal.price_live` / `price_reference` / `price_role` | 同 v2 |
| `deal.price_flag` / `confidence` | 存疑 / 单源 |

金额一律「分」。

## 5. 接口（未变，除新增只读字段）

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/snapshot` | 全量（含 site / model_groups / 历史字段）|
| GET | `/api/jd-price?product_id=` | 单商品京东实时价（按需，5 分钟缓存）|
| GET/POST | `/api/jd-match` | 待确认 / 确认京东对应关系 |
| GET/POST | `/api/user-coupons` | 用户券（内存 TTL 10 分钟）|
| POST | `/api/quote` | 券后价计算 |
| POST | `/api/refresh` | 只采 ZOL（按钮文案：「更新参考价」）|
