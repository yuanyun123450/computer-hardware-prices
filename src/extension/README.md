# 比价助手扩展 · 安装与说明

## 它做什么

在你自己打开的京东商品页右下角，加一个小面板。**你点“同步我的券”时**，它把页面上可见的「满 X 减 Y」券发到本机比价服务（`http://127.0.0.1:8787`），用于算**你自己的**券后价。

## 它不做什么（重要）

- ❌ 不读 cookie、不读登录态、不改页面
- ❌ 不上传任何服务器（只发本机 `127.0.0.1`）
- ❌ 不自动触发，必须你点
- ❌ 不保存券（后端只在内存里放 10 分钟）

## 安装（Chrome / Edge）

1. 打开 `edge://extensions`（或 `chrome://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载解压缩的扩展」，选这个目录 `src\extension\`
4. 打开任意京东商品页（例如 https://item.jd.com/100378244340.html），右下角会出现面板

## 前置条件

- 本机比价服务要开着：`D:\nodejs\node.exe src\serve.mjs`
- 要在京东页**登录**后，个人券才可见（未登录只有公开信息）

## 现在的局限（诚实说明）

- 京东 PC 商品页在显卡类**普遍没有公开券区**（实测 3/3 为空），所以面板经常显示“找到 0 张券”——**这不是坏了**
- 京东改版频繁，券的容器选择器可能变；`content.js` 里 `collectCouponTexts()` 已写了多组选择器 + 整页兜底，若仍抓不到，改这一个函数即可
- 解析规则只认「满 X 减 Y」「无门槛立减 X」，其他表述（如折扣券 8 折）暂不识别

## 调试

在京东页按 F12，Console 里手动跑：

```js
// 看能收集到哪些"像券"的文本
console.log(collectCouponTexts?.() ?? "函数未暴露");
```

（当前实现在面板点击时执行；如需手动调试，可把 `collectCouponTexts` 挂到 `window` 上，一行即可。）
